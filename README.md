# Smart Resume Analyzer

## 📌 Problem Statement
Recruiters manually analyze resumes, which is time-consuming and inconsistent.  
This project automates resume analysis by extracting skills and matching them with job requirements.

## 🚀 Features
- Extracts text from PDF resumes
- Cleans and normalizes resume content
- Automatically extracts technical skills
- Easy to extend for job matching and scoring

## 🛠️ Tech Stack
- Python
- Flask (upcoming)
- NLP (basic keyword matching)
- PyPDF2

## ⚙️ How It Works
1. Upload resume PDF
2. Extract raw text from PDF
3. Clean and normalize text
4. Match extracted text with predefined skill set
5. Display matched skills
